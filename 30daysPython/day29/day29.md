# 🌐 REST API Basics 

## 📌 Overview

REST (Representational State Transfer) is one of the most widely used architectural styles for building web services. A REST API enables communication between clients (such as web browsers, mobile apps, or frontend applications) and servers using standard HTTP methods.

This project introduces the fundamental concepts of REST APIs using **FastAPI** with simple examples. Understanding these concepts is essential for becoming a Python Backend Developer.

---

# 📚 Topics Covered

## 1. What is a REST API?

Learn how clients and servers communicate over HTTP using REST principles and exchange data in JSON format.

**Concepts Learned**

* Client-Server Architecture
* HTTP Communication
* Request and Response Cycle
* JSON Data Exchange

---

## 2. HTTP Methods

Understand the different HTTP methods used to perform operations on resources.

**Concepts Learned**

* GET
* POST
* PUT
* PATCH
* DELETE
* CRUD Mapping

---

## 3. Resources

Learn how REST APIs represent data as resources that are accessed using unique URLs.

**Concepts Learned**

* Resource-Based Design
* URI (Uniform Resource Identifier)
* Collection Endpoints
* Individual Resource Endpoints

---

## 4. Path Parameters

Retrieve or manipulate a specific resource by passing values directly in the URL.

**Concepts Learned**

* Dynamic URLs
* Path Variables
* Resource Identification
* Automatic Type Validation

---

## 5. Query Parameters

Pass optional values in the URL to filter, search, sort, or paginate data.

**Concepts Learned**

* Filtering
* Searching
* Optional Parameters
* URL Queries

---

## 6. Request Body

Send structured data from the client to the server when creating or updating resources.

**Concepts Learned**

* JSON Request Body
* Pydantic Models
* Data Validation
* Client Input Processing

---

## 7. Response

Return structured JSON data from the server after processing a request.

**Concepts Learned**

* JSON Responses
* Response Objects
* API Output
* Client Communication

---

## 8. HTTP Status Codes

Return meaningful HTTP status codes to indicate whether a request was successful or failed.

**Concepts Learned**

* 200 OK
* 201 Created
* 204 No Content
* 400 Bad Request
* 401 Unauthorized
* 403 Forbidden
* 404 Not Found
* 500 Internal Server Error

---

## 9. Headers

Exchange additional information between the client and server using HTTP headers.

**Concepts Learned**

* Request Headers
* Response Headers
* Metadata
* Browser Information
* Authorization Headers

---

## 10. CRUD Operations

Implement the four basic database operations using REST API endpoints.

**Concepts Learned**

* Create
* Read
* Update
* Delete
* Resource Management

---
